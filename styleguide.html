Logofamilie

Fundament assets/logos/ Quelle: tools/build-logos.py

Alle Logos werden aus einer Quelldatei abgeleitet und sind damit in Form und Abstand identisch. Neu bauen mit python3 tools/build-logos.py. Die Wortmarke ist Nunito Black, Claim und Arbeitsbereiche stehen in Gochi Hand.

Dachmarke und Arbeitsbereiche

Die Arbeitsbereiche tragen dieselbe Sperrung wie die Dachmarke – an der Stelle des Claims steht ihr eigener Schriftzug. Eine eigene Farbe haben sie nicht; das bleibt das Unterscheidungsmerkmal der Eigenmarken. Für data-brand="praevention" und "rehabilitation" gibt es deshalb bewusst keinen [data-brand]-Block in main.css: Das Logo kommt aus LOGOS, die Farben aus :root. Alle vier Varianten messen identisch 2951 × 765 px und teilen --logo-anteil: 0.658, damit das Logo beim Seitenwechsel nicht in der Größe springt.

Design Tokens

Fundament :root Quelle: styles/main.css

Das komplette Farb-, Radius-, Schatten- und Abstands-System als CSS-Variablen. Alle anderen Komponenten greifen ausschließlich auf diese Tokens zu – ein Wert wird einmal zentral geändert und wirkt überall.

Markenarchitektur: Die Dachmarke ist blau. Die Arbeitsbereiche Prävention und Rehabilitation haben kein eigenes Logo und keine eigene Farbe – sie laufen in der Dachmarke und werden über den Handschrift-Kicker benannt. Die Wohngruppe ist Teil der Rehabilitation und kein eigener Arbeitsbereich. Nur die beiden Eigenmarken Straßencafé (Rot) und Dienstleistungen (Grün) tragen eigene Logos und Farben. Umgeschaltet wird pro Seite über <body data-brand="strassencafe">; alle Komponenten lesen danach --brand.

Kontrast: Weiß auf dem reinen Markengrün erreicht nur 3,6:1. Textflächen nutzen deshalb --gruen-tief (4,7:1); das reine Markengrün bleibt Logo und Akzent vorbehalten.

CSS-Quelle (Auszug) 
:root {
  /* Markenfarben */
  --blau:        #094684;  /* Dachmarke */
  --rot:         #781e00;  /* Straßencafé */
  --gruen:       #009d06;  /* Dienstleistungen (Logo, Akzent) */
  --gruen-tief:  #00871a;  /* Dienstleistungen (Textflächen) */

  /* Aktives Theme – von [data-brand] gesetzt */
  --brand: var(--blau);
  --brand-flaeche: var(--blau);
  --brand-dunkel:  var(--blau-dunkel);
  --brand-hell:    #c8d8e2;
  --brand-zart:    rgba(9,70,132,0.07);

  /* Text auf der Markenfläche – zwei Stufen statt beliebiger
     Deckkraftwerte. Im Dienstleistungs-Theme laufen beide auf
     volles Weiß: auf dem Markengrün trägt keine Abstufung. */
  --auf-brand:       rgba(255,255,255,0.82);
  --auf-brand-leise: rgba(255,255,255,0.66);

  /* Feine Trennlinie – vorher dreifach als Literal verstreut */
  --border-soft:   1px solid rgba(5,41,55,0.08);

  /* Schrift */
  --font-head: 'Nunito', sans-serif;
  --font-body: 'Nunito Sans', sans-serif;
  --font-hand: 'Gochi Hand', cursive;

  --radius-sm: 6px;  --radius-md: 12px;
  --radius-lg: 16px; --radius-xl: 24px; --radius-pill: 999px;

  --max-width: 1100px;  --nav-height: 88px;
}

Icons

Fundament .ic .ic-* Quelle: styles/layout.css

Strich-Icons als CSS-Maske statt Emojis. Die Form steckt in der Variable --ic, die Farbe kommt über currentColor – dadurch nehmen die Icons automatisch die Farbe ihres Kontexts an: Markenfarbe auf Weiß, Weiß auf einer Markenfläche. Gleiches Prinzip wie die Social-Icons im Footer.

Hauptnavigation / Header

Global #main-nav Quelle: scripts/includes.js + styles/navigation.css

Fixierter Kopf mit Logo, Textlinks, Dropdown „Arbeitsbereiche", hervorgehobenem Spenden-Button (.nav-cta) und Burger-Menü unter 900 px. Der aktive Link wird per Balken markiert; beim Scrollen erscheint ein Schatten. Live-Beispiel: der Seitenkopf ganz oben auf dieser Seite. Header & Footer werden per data-include aus einem JS-Template injiziert (funktioniert auch ohne Server).

HTML (aus dem includes.js-Template; ${R} = Pfad-Präfix zur Wurzel) 
<nav id="main-nav" aria-label="Hauptnavigation">
  <a class="nav-logo" href="${R}">
    <img src="${R}assets/logos/handsofhope-logo.webp" alt="Hands of Hope">
  </a>
  <ul class="nav-links" id="nav-links">
    <li><a href="${R}ueber-uns/">Über uns</a></li>
    <li class="nav-has-dropdown">
      <a href="${R}#bereiche">Arbeitsbereiche</a>
      <ul class="nav-dropdown">
        <li><a href="${R}rehabilitation/">🏠 Rehabilitation</a></li>
        <!-- … weitere Bereiche … -->
      </ul>
    </li>
    <li><a href="${R}blog/">Blog</a></li>
    <li class="nav-cta"><a href="${R}ueber-uns/#spenden">❤ Spenden</a></li>
  </ul>
  <button class="burger" id="burger" aria-label="Menü öffnen">
    <span></span><span></span><span></span>
  </button>
</nav>
Einbindung auf jeder Seite: <div data-include="header"></div> – scripts/includes.js ersetzt das durch die echte Navigation und setzt aktive Links.

Spendenart-Umschalter

Tastaturbedienbare Tabs nach dem ARIA Authoring Practices Guide – scripts/tabs.js. Die Buttons sind gewöhnliche .btn.btn-sm: der aktive Tab trägt .btn-primary, die übrigen .btn-ghost; die Panels schalten über das hidden-Attribut. Pfeiltasten, Home und End wandern durch die Gruppe, gesucht wird nur innerhalb der jeweiligen [role="tablist"] – mehrere Gruppen pro Seite stören sich also nicht.

HTML 
<div role="tablist">
  <button role="tab" id="t1" aria-controls="p1" aria-selected="true"
          class="btn btn-sm btn-primary">Einzelspende</button>
</div>
